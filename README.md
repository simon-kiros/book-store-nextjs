# Bookstore-client

Bookstore Nextjs client project Description

- Nextjs Framework
- Tailwind CSS : Reponsive UI library
- Recoil : State management library
- Axios : HTTP client library
- React infinite scroll component : Infinite scroll component

## Installation

```bash
$ npm install
```

## Running the app

```bash
# development
$ npm run dev

# production mode
$ npm run build
```

## App Home Path

http://localhost:3000/books
